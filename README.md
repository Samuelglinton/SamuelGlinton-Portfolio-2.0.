# S. Samuel Glinton — Portfolio 2.0

A responsive Premium Tech portfolio using a white, navy and electric-blue palette.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, theme and animations
- `script.js` — mobile navigation, reveal effects and scroll progress
- `assets/profile.jpg` — add your own profile photo here

## Add your profile photo
1. Choose your preferred real profile photo.
2. Rename it exactly to `profile.jpg`.
3. Upload it into the `assets` folder.
4. Keep the file path as `assets/profile.jpg`.

The page shows a simple initials placeholder until you add the photo.

## Publish with GitHub Pages
1. Open your repository on GitHub.
2. Upload all files and the `assets` folder, keeping the folder structure.
3. Go to Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

## Important before publishing
Review all dates, role descriptions and project details for accuracy. Add a resume PDF only after you have uploaded your approved resume. Do not publish personal contact details unless you want them public.
